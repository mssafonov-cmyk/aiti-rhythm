# Доступы и личные данные

Публикуйте общие исходники и собранный из них Setup.exe с SHA256SUMS.txt.
Не загружайте на GitHub папку личных данных установленной программы.
Сборка использует белый список; исходная история другого репозитория не переносится.

Панель читает метаданные журналов Codex/Claude, включая названия проектов,
статусы и счетчики. Тексты сообщений не записываются в snapshot.json.
Снимок, логи, пути профилей и настройки принадлежат пользователю компьютера.
Не прикладывайте их к публичным issue без проверки содержимого.

Ссылки календаря, имя входа, пароль и команды внешних источников сохраняются в connections.sealed через
Windows DPAPI для текущего пользователя. Это защищает сохраненный файл,
но не защищает от программы, уже работающей с правами того же пользователя.
Обычные настройки в connections.json секретов не содержат.
Отключение календаря удаляет сохраненные календарные секреты, сохраняя независимые
настройки Claude; после смены
аккаунта в Codex используйте его штатный вход, панель авторизацию не копирует.

iCal и OData используют только HTTPS GET без перехода по редиректам.
CalDAV использует чтение/поиск событий; пароль приложения может технически
давать больше прав, но панель не создает и не меняет события.
Календарь 1С должен быть ограничен правами и запросом вашей публикации:
подпись источника сама по себе не подтверждает владельца всех его событий.

Кубик получает JPEG в локальной сети по штатному HTTP. Устройство обычно
не аутентифицирует зрителя: по умолчанию названия встреч на нем выключены.
Секреты календаря и учетные данные AI-инструментов на кубик не передаются.
Вывод использует до пяти собственных имен файлов (JPEG и GIF напоминания), не удаляет чужие картинки,
не меняет прошивку, яркость или сеть устройства.

Отключенные дополнительные источники не запускают новые сетевые запросы.
Уже начатое чтение может завершиться до сетевого таймаута.

Внешние сборщики — явно заданные пользователем программы с его правами.
В поставке нет исполняемых команд с личными адресами, SSH-ключей или учетных записей.
Этот режим нужен для совместимости; проверка безопасности произвольной команды
остается ответственностью ее владельца. Ошибки источников сохраняются как тип
ошибки, без текста исключения с возможными URL/секретами.
