АйТи:Ритм 1.3.1 — подключение своих источников

ВИД ПАНЕЛИ
В настройках откройте вкладку «Вид»: календарь, сессии, лимиты и расход можно
скрывать независимо, не удаляя подключения. Высота подбирается автоматически;
для ручного изменения отключите подбор высоты. Список сессий прокручивается.
В лимитах недельный остаток и тонкая пятичасовая полоска под ним, если лимит
передан источником. Без заглушек и повторных подписей; период/сброс — по наведению.
Дата сброса берётся из источника. Если её нет, показано «Дата не передана»;
частота чтения данных и дата сброса квоты — разные вещи. Местный Claude может
передавать квоту из своего обновляемого кэша .claude.json; без этих данных
квота не вычисляется из токенов. Во внешнем JSON используйте five_hour/seven_day
с used_percentage и необязательным resets_at с часовым поясом.

УСТАНОВКА
Windows 10 (1809+) / Windows 11, x64. Откройте Setup.exe из официального Releases.
Python и библиотеки уже внутри. Интернет для самой установки не требуется.
Права администратора не запрашиваются; программа устанавливается текущему пользователю.
Автозапуск — отдельная галочка. Ярлыки находятся на рабочем столе и в меню Пуск.
Кнопка «−» прячет окно в трей, полный выход — через меню трея.

КОД И ЛИЧНЫЕ ДАННЫЕ
Программа: %LOCALAPPDATA%\Programs\AITI Rhythm.
Личные настройки, снимки, журналы: %LOCALAPPDATA%\AITI\Rhythm\data.
Обновление меняет программу, сохраняя личные настройки. Удаление через параметры
Windows удаляет программу и автозапуск, но сохраняет папку личных данных.
Для полного удаления удалите эту папку вручную после выхода из программы.
Нельзя публиковать папку данных. В Git хранятся общие исходники, не ваши подключения.
Версия и исходный коммит доступны в шестерёнке → «О программе».

CODEX И CLAUDE CODE
Войдите обычным способом в свои инструменты и запустите хотя бы одну сессию.
Панель ищет Codex и папки .codex/.claude текущего пользователя.
CODEX_HOME и CLAUDE_CONFIG_DIR учитываются. В настройках можно указать другие папки.
Для WSL: путь вида \\wsl.localhost\Ubuntu\home\user\.claude.
Codex открывает чат нажатием на строку. Для Claude показываются статусы и токены.
Статусы основаны на доступных метаданных журналов; пауза не считается ожиданием ответа.
Точная квота Codex доступна не во всех аккаунтах. Для локального Claude нужен
свежий кэш использования, который обновляет сам Claude; иначе квота недоступна.
Расход токенов не равен стоимости или остатку квоты.

КАЛЕНДАРЬ — ПО ЖЕЛАНИЮ
Шестерёнка → Подключения → «Показывать встречи».
Google: Настройки календаря → Интеграция календаря → Закрытый адрес в формате iCal.
Яндекс: настройки нужного календаря → Экспорт → ссылка iCal.
Вставьте личную HTTPS-ссылку в защищенное поле, не делайте календарь общедоступным.
CalDAV: прямой адрес конкретного календаря, логин и пароль приложения.
OData: HTTPS-запрос к JSON-коллекции, свои права и соответствие полей id/subject/start/end/url.
Нужны правильные ограничения на стороне публикации; универсальных реквизитов 1С нет.
Ответ с пагинацией считается ошибкой — сузьте диапазон запроса.
Окно -7/+14 дней, опрос не чаще минуты; фактическая свежесть зависит и от сервиса.
Повторения DAILY/WEEKLY/MONTHLY/YEARLY, исключения и отмены поддерживаются.
События на весь день видны в дневном списке, но не запускают минутное напоминание.
При ошибке прежние встречи помечаются устаревшими. При отключении карточка исчезает,
а сохраненные календарные доступы удаляются. Пароли и личные ссылки защищаются Windows DPAPI.

КУБИК — ПО ЖЕЛАНИЮ
Штатный протокол HelloCubic-Lite / SmallTV-Ultra. Укажите частный IPv4 устройства
в своей сети, поворот и разрешение названий. Названия встреч по умолчанию скрыты.
Вывод меняет картинку и отключает автослайдшоу устройства. Карточки: лимиты,
сессии, токены, календарь. Встреча за пять минут получает приоритет и мигающую рамку.
До пяти собственных JPEG/GIF переиспользуются; неизменные картинки не записываются
повторно. Чужие файлы не удаляются.
Сеть, яркость и прошивка не меняются. Конкретная прошивка требует проверки на устройстве.

ВНЕШНИЙ ИСТОЧНИК — ДЛЯ РАНЕЕ НАСТРОЕННЫХ КОРПОРАТИВНЫХ ПОДКЛЮЧЕНИЙ
Дополнительный режим читает UTF-8 JSON от явно указанной локальной команды.
Команда задается JSON-массивом: исполняемый файл, затем каждый аргумент отдельно.
Системная оболочка не используется. Команды хранятся в личном DPAPI-файле.
Указывайте только доверенный сборщик: программа выполняется с вашими правами.
Существующий read-only collect.py можно подключить через режим --legacy-root
RhythmCore.exe, указав --legacy-provider calendar или claude и свою папку.
Ни адреса серверов, ни аккаунты, ни исходные персональные настройки в поставку не входят.

ANTIGRAVITY CLI
Автоматический профиль: ~/.gemini/antigravity-cli. Другой профиль укажите на
вкладке AGY. Тестовые/IDE профили с ним не смешиваются. Читаются SQLite-названия
и статусы, числовые счётчики PLANNER_RESPONSE из brain/*/.system_generated/logs/
transcript.jsonl. Секреты и тексты сообщений не сохраняются в кэше счётчиков.
Ритм не запускает agy/модели и не меняет настройки Antigravity. Нативный объём
Antigravity=input_tokens+output_tokens; cache_read_tokens отдельно (как в native
JSON total_tokens). Квоты /usage не вычисляются по токенам. Неполученная история
не заменяется нулевым графиком. Общий график использует единую вертикальную шкалу
и реальные интервалы15мин; момент расхода берётся из исходного журнала.
