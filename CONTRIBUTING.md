# Одна версия для всех

Изменения панели, сборщика и установщика вносятся в этот репозиторий.
Личная установка использует тот же Setup.exe, который предлагается другим людям.
Персональные настройки не должны превращаться в отдельную копию программы.

Программа устанавливается в профиль пользователя, а изменяемые данные — отдельно:
`%LOCALAPPDATA%/AITI/Rhythm/data`. Не копируйте эту папку в Git и не добавляйте
действующие подключения или снимки в тесты. Нужны только синтетические примеры.

Для разработки на Windows: установите requirements-build.txt в отдельное
виртуальное окружение, выполните `python -m unittest discover` и
`python rhythm_app.py --self-test --data-dir <временная-папка>`.

Для Setup.exe нужен Inno Setup 7. Команда сборки:
`python build_installer.py --iscc <путь-к-ISCC.exe>`.
Тестируйте именно замороженную программу: локальный Python может скрывать
недостающие зависимости пакета. Проверяйте установку/обновление/удаление под
обычным пользователем, без Python в PATH. Проверьте секреты в исходниках,
в дереве собранной программы и в извлеченном содержимом установщика.

После тестирования коммита соберите окончательный установщик. Он содержит
build-info.json с версией и идентификатором исходного коммита.
Изменения после сборки требуют нового пакета и проверки.
В Releases публикуются Setup.exe и SHA256SUMS.txt. Исходники доступны из Git.
